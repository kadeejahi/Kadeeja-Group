# Initial Requirements

1. Student can create and submit support requests.
2. student can view the status of their requests.
3. Reviewers can view submitted requests.
4. Reviewers can update request information and status.
5. Reviewers can add updates to requests.
6. Reviewers can record how a request was resolved.
7. The system will maintain a history of request updates and status changes.
8. Students and reviewers will have different access permissions.
