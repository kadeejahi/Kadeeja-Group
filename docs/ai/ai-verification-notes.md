# Ai Verification Notes

## Purpose

Ai intervention must be treated as a recommendation on what action to take. Reviewing the recommendation is important in order to connect it to the project goal and path. Make sure to always review Ai generated content before pushing it into the repository.
## Expectations

- After generating content with Ai, please make sure to fully understand what the Ai is recommending to you.
- Review it based off where the recommendation will be added on to (which file) and how it will fit along side existing work.
- DO NOT COPY PASTE. Write the recommendation yourself as a separate way to review the recommendation. (Could help further understand the recommendation)


## Verification Process

**Ask these Questions**

1. What file is being changed and what other files will be affected by this change?
2. Is this change/addition in line with the architectural goal?
3. Are there any holes in the logic provided by the AI that can and should be covered up?
