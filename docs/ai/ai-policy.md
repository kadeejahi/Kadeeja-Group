# Ai Policy

## Purpose

AI should be used as a tool meant to help boost our understanding and generate code faster. It should only be used as a tool and not as an extra team member. AI use should be kept to a reasonable amount and should be shared with the Operations & Evidence lead and Back-up for logging purposes.  
## Expectations

**1. Basic AI Use**
- Prompting should be as specific as possible as to avoid the AI from going past the planned scope.
- Always review code proposed by AI and check its compatability with current code.

**2. AI Use Logging**
- AI use should be shared with Operations & Evidence Lead & Backup.
- Shared use should include: Date Used, Tool Used (Gemini, Claude, ChatGPT, etc.), Purpose of use, Artifacts/Activites, and Human Verification.
- Logs will be added to dedicated branch where AI was used.
- Ai will not be logged if its suggestion is not added in any way to an artifact/activity.

**3. Ai Restrictions**
- Ai will not be used to create full policy files
- Ai suggestions should not be copy-pasted, especially if it's code related.
