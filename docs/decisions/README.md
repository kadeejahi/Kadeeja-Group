# Engineering Decision Records

This directory contains Architecture and Engineering Decision Records
(ADRs) for significant project decisions.

Create a decision record when the team makes a choice involving meaningful
alternatives, tradeoffs, risks, constraints, or downstream consequences.

Use sequential names:

`ADR-001-short-title.md`
`ADR-002-short-title.md`
`ADR-003-short-title.md`

Do not use decision records for routine implementation details.

Keep decision records linked to related requirements, issues, pull
requests, architecture evidence, and verification evidence where applicable.

Sakai defines course requirements. This directory preserves the team's
project-specific decision evidence.
